# Recetarios 2º DAM

Apuntes por bloques (DEINT, PSP, PMDM) publicados con GitHub Pages.

Los originales viven en Google Drive (`G:\Mi unidad\2º DAM\...\Recetario\`).
`sync.ps1` los copia aquí y hace commit y push si alguno ha cambiado.
Una tarea programada de Windows ("Recetarios DAM sync") lo lanza cada 10 minutos mediante `sync.vbs`, sin abrir ventana.
