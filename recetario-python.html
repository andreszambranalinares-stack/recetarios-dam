1.1 Antes de escribir: entrada, proceso y salida

Programar consiste en expresar una solución mediante instrucciones que el ordenador pueda ejecutar con unos datos concretos. Antes de escribir código, identifica los datos de entrada, las operaciones necesarias y el resultado que debe obtenerse. Para contar aprobados, el programa recibe unas notas, compara cada una con cinco y muestra cuántas cumplen esa condición. Podemos resolver este primer problema con variables, condiciones y un bucle.

Prepara dos ejemplos a mano, incluido un caso límite, es decir, una situación que pruebe los extremos o la ausencia de datos. Con las notas [4, 5, 8] esperas dos aprobados. Si la lista está vacía, esperas cero. Estos resultados te permiten comprobar después si el programa hace lo que necesitas. Divide la solución en pasos pequeños. Primero inicializa el contador a cero, después recorre las notas y aumenta el contador cuando corresponda. Muestra el total al terminar el recorrido.

Conviene distinguir tres clases de errores. Un error de sintaxis impide que Python analice correctamente las instrucciones, por ejemplo, si falta el signo de dos puntos de un if. Un error de ejecución aparece al intentar una operación que no se puede realizar, como dividir entre cero. Un error lógico permite que el programa termine, pero produce un resultado incorrecto, como contar solo las notas mayores que cinco y olvidar el cinco. El depurador permite observar la ejecución paso a paso. Los casos de prueba permiten comparar el resultado obtenido con el esperado.

Sigue el ejemplo: aprobados empieza en cero antes del bucle. Las notas 5 y 8 cumplen la condición, así que el contador aumenta dos veces. print está fuera del bucle y muestra el total una sola vez. Si inicializaras aprobados dentro, perderías lo contado en las vueltas anteriores.

1.3 Nombres, tipos y decisiones

En Python, una variable es un nombre asociado a un objeto. Puedes escribir edad = 20 sin declarar previamente su tipo, como harías con int edad en Java. El objeto sigue teniendo un tipo concreto. Por ejemplo, 20 es un int y "20" es un str, una cadena de caracteres. Intentar sumar directamente un entero y una cadena provoca TypeError, una excepción que indica que los tipos no son compatibles con esa operación.

input devuelve una cadena con el texto introducido, aunque el usuario haya escrito cifras. int(texto) permite convertir ese texto en un entero si su contenido es válido. Por ejemplo, int("20") devuelve 20, mientras que int("veinte") provoca ValueError. Esta excepción indica que el valor recibido no sirve para la conversión solicitada.

La indentación, es decir, los espacios al comienzo de una línea, indica qué instrucciones pertenecen a cada bloque. Utiliza cuatro espacios por nivel y evita mezclar espacios y tabuladores. En Java reconoces los bloques por las llaves. En Python debes fijarte en la indentación que sigue a los dos puntos de if, for o while. En el ejemplo, la asignación a estado pertenece a if o a else según su posición, y print pertenece al bucle.

if comprueba una condición y ejecuta su bloque cuando se cumple. elif permite comprobar otra condición y else contiene las instrucciones que se ejecutan cuando ninguna de las anteriores se cumple. El operador == compara valores, mientras que = asigna un valor a un nombre. and exige que se cumplan ambas condiciones, or permite que se cumpla alguna y not invierte el valor lógico de una condición.

for recorre los elementos de un iterable, un objeto del que podemos obtener elementos sucesivamente, como una lista o un range. while repite su bloque mientras se cumpla una condición. Por ejemplo, range(1, 4) permite recorrer 1, 2 y 3. El segundo límite queda excluido.

Al convertir a bool, una cadena vacía se considera falsa y cualquier cadena con contenido se considera verdadera. Por eso bool("False") devuelve True. Para interpretar una respuesta como "sí" o "no", elimina los espacios exteriores con strip(), pasa el texto a minúsculas con lower() y compáralo con las respuestas admitidas. Esas operaciones preparan el texto antes de comprobarlo.

Sigue el ejemplo: range(0, 3) proporciona 0, 1 y 2. En la primera vuelta, plazas vale 0 y se ejecuta el bloque de if. En las otras dos se ejecuta else. print se ejecuta en cada vuelta y muestra 0: Completo, 1: Disponible y 2: Disponible en líneas separadas.

1.4 Expresiones, cadenas y conversiones

Una expresión es una combinación de valores, variables u operadores que Python evalúa para obtener un resultado. Por ejemplo, 3 + 4 es una expresión cuyo valor es 7. Python distingue 7, 7.0 y "7", que son un entero (int), un número de coma flotante (float) y una cadena (str). Puedes consultar su tipo con type(7), type(7.0) o type("7").

Los operadores +, - y * permiten sumar, restar y multiplicar números. El operador / realiza una división y, con los enteros de estos ejemplos, devuelve un float. Así, 7 / 2 produce 3.5. El operador // divide y redondea el cociente hacia el entero menor o igual que él. Por eso 7 // 2 da 3 y -7 // 2 da -4. Con operandos enteros, el resultado de // también es entero. El operador % obtiene el resto de la división, de modo que 7 % 2 da 1. Utiliza paréntesis cuando ayuden a reconocer el orden de los cálculos.

input devuelve texto, así que "4" + "6" une ambas cadenas y produce "46". Para calcular una media, convierte primero cada respuesta con int o float según los datos que admita el programa. float("4.5") acepta el punto decimal. Una coma escrita por el usuario requiere un tratamiento específico. Convertir el tipo tampoco comprueba el rango. int("-3") produce un entero válido para Python, pero una edad negativa debe rechazarse mediante una condición.

Una cadena f, o f-string, lleva una f delante de las comillas y permite insertar expresiones entre llaves. En f"{total:.2f}", el formato :.2f muestra el valor con dos cifras decimales. El formato solo afecta al texto mostrado y conserva el valor de la variable.

Los float tienen precisión limitada porque representan los números en binario. Son adecuados para las medias de estos ejemplos. Para importes que deban conservar una cantidad exacta de céntimos, podemos realizar los cálculos con céntimos enteros, como en el ejemplo, o estudiar el tipo Decimal. Mostrar dos decimales y calcular con exactitud son cuestiones diferentes.

Sigue el ejemplo: El precio es 1250 céntimos y se compran tres unidades, de modo que total contiene 3750. La primera línea muestra Total: 37.50 EUR. La segunda muestra 3 1, que son el cociente redondeado hacia abajo y el resto de dividir 7 entre 2.

Desde Java: En Java declaras el tipo de una variable, por ejemplo, int edad = 20. En Python escribes edad = 20 y el objeto asociado es un int. str(edad) obtiene su representación como texto. Las cadenas f permiten insertar valores de forma comparable al formato de cadenas de Java. Recuerda también que, con enteros, / tiene un comportamiento distinto en ambos lenguajes.

Ojoint("3.5") provoca ValueError porque ese texto no representa un entero. int(3.5) da 3 e int(-3.5) da -3. Al convertir un float con int se elimina la parte decimal, acercándose a cero. El operador // sigue la regla de redondeo hacia abajo explicada en este apartado.

1.5 Decidir y repetir con un criterio

if ejecuta un bloque si se cumple una condición. Los elif se comprueban en orden cuando las condiciones anteriores han resultado falsas. else recoge los casos restantes. Dentro de una misma estructura if/elif/else se ejecuta como máximo uno de esos bloques. Si compruebas nota >= 5 antes que nota >= 9, una nota de nueve cumplirá la primera condición y se clasificará en ese bloque. Coloca primero las comprobaciones más restrictivas cuando ese sea el criterio del problema. La expresión 0 <= nota <= 10 permite comprobar que la nota está dentro del intervalo, incluidos sus extremos.

Utiliza for cuando necesites recorrer datos o repetir una tarea un número conocido de veces. while resulta adecuado cuando debes repetir hasta que cambie una condición, como al solicitar un dato hasta que sea válido. Identifica siempre qué permite terminar. Si la condición de while se mantiene verdadera y no se ejecuta ninguna salida, el bucle seguirá repitiéndose.

break termina el bucle más cercano que lo contiene. continue omite las instrucciones restantes de esa vuelta y pasa a la siguiente. En un while, eso implica volver a comprobar la condición. Emplea estas instrucciones cuando faciliten seguir la lógica del programa.

Un acumulador conserva una suma que va creciendo, mientras que un contador registra cuántas veces ocurre algo. Ambos suelen inicializarse antes del bucle para conservar su valor entre vueltas. Si necesitas calcular un máximo o una media, decide antes qué debe ocurrir si faltan datos. En el caso profesional de esta unidad se aceptan exactamente cinco notas válidas antes del cálculo. La indentación indica si una instrucción se ejecuta en cada vuelta o una sola vez al terminar.

Sigue el ejemplo: suma comienza en cero y pasa a valer 2, 9 y 14 tras cada nota. Después del bucle, len(notas) devuelve 3 y se calcula 14 / 3. El formato :.1f muestra la media con una cifra decimal, por lo que aparece Media: 4.7.

Desde Java: for nota in notas recorre valores, como un for-each de Java. range(5) recorre 0, 1, 2, 3 y 4; el límite final se excluye.

1.6 Validar datos y recuperarse de una entrada incorrecta

Para validar una entrada numérica, comprueba primero si el texto se puede convertir al tipo esperado. Después comprueba si el valor pertenece al rango permitido. int("hola") provoca ValueError. Cuando ocurre, Python interrumpe esa conversión y busca un bloque except que atienda la excepción.

Coloca dentro de try la operación que puede provocar el error previsto. except ValueError contiene las instrucciones que se ejecutarán si falla la conversión. Un bloque try pequeño ayuda a identificar el origen del fallo. En el ejemplo, después del aviso se ejecuta continue para iniciar otra vuelta del bucle.

Si la conversión tiene éxito, todavía hay que comprobar el rango. Un entero como -1 puede convertirse correctamente y quedar fuera de las notas admitidas. Solo las entradas que superan ambas comprobaciones se añaden a notas. Así, len(notas) cuenta notas aceptadas y el bucle termina cuando reúne tres.

Captura las excepciones que sepas tratar. Un NameError por escribir mal una variable requiere corregir el programa. Una respuesta no numérica es una situación previsible y podemos pedir al usuario que vuelva a intentarlo. Este ejemplo acepta enteros de 0 a 10. Si se admitieran decimales, habría que ajustar la conversión, los requisitos y las pruebas de forma coherente.

Sigue el ejemplo: Introduce hola, -1, 0, 5 y 10, en ese orden. hola falla al convertir y -1 queda fuera del rango. Los otros tres valores se añaden a notas. El bucle termina y muestra la media 5.0.

OjoSi aumentas el contador de notas antes de validar la entrada, un intento incorrecto contará como una nota recibida. Aumenta ese contador o añade el dato a la lista únicamente después de aceptarlo.

1.7 Leer un traceback y comprobar una corrección

Cuando una excepción interrumpe el programa, Python suele mostrar un traceback, el listado de las llamadas que llevaron al error. Empieza por la última línea, donde aparecen el tipo de excepción y su mensaje. Después busca la línea de tu archivo que se estaba ejecutando. Si una suma provoca TypeError, revisa los valores y tipos de sus operandos. Ante NameError, comprueba si el nombre coincide con el que definiste.

Un error lógico puede terminar sin mostrar un traceback. Si esperabas varios aprobados y obtienes un resultado distinto, anota cada nota y el valor del contador tras procesarla. También puedes detener el programa con un punto de interrupción y avanzar paso a paso. Revisa dónde inicializas el contador y si la condición debe ser >= 5. Tras corregirlo, repite tanto el caso que fallaba como otro que ya funcionaba.

Conserva una tabla con los datos de entrada, el resultado esperado, el resultado obtenido y una explicación de la diferencia. El ejemplo utiliza assert para comprobar una condición durante el estudio. Más adelante aplicaremos estas comprobaciones a funciones y organizaremos grupos de pruebas con unittest. Una prueba debe comprobar un comportamiento observable y ser capaz de detectar un error concreto.

Sigue el ejemplo: assert aprobados == 2 comprueba que el contador tiene el valor esperado. Si la condición es falsa, Python provoca AssertionError. Si es verdadera, continúa y muestra Comprobación superada. Utiliza assert para estas comprobaciones de estudio y condiciones o excepciones explícitas para validar entradas, ya que Python permite desactivar las instrucciones assert.

2.1 Una estructura para cada necesidad

Python ofrece distintas colecciones para organizar varios datos. Una lista conserva el orden de sus elementos, admite valores repetidos y permite añadir, eliminar o sustituir elementos. Una tupla también conserva el orden, pero sus posiciones quedan fijadas al crearla. Si contiene un objeto que se puede modificar, como una lista, ese objeto interior puede cambiar. Llamamos mutable a un objeto que puede modificarse e inmutable a uno que conserva su valor. La modificación de un objeto también se denomina mutación.

Un conjunto, de tipo set, reúne elementos sin repetición y permite comprobar si un elemento pertenece a él. Su orden de recorrido carece de una garantía que podamos utilizar para presentar datos. Un diccionario, de tipo dict, asocia una clave única con un valor. Por ejemplo, podemos utilizar "PC01" como clave para localizar la ficha de un equipo. Las listas, los conjuntos y los diccionarios se parecen, por su finalidad, a ArrayList, HashSet y Map de Java, aunque sus reglas concretas difieren.

Recorre directamente los elementos con for cuando solo necesites sus valores. enumerate permite obtener a la vez la posición y el elemento. Para recorrer claves y valores de un diccionario, utiliza su método items(). El acceso datos[clave] provoca KeyError si la clave está ausente. datos.get(clave, alternativa) devuelve la alternativa en ese caso. Decide si una ausencia es una situación prevista o un fallo que debe comunicarse.

Una comprensión permite construir una colección mediante una expresión que recorre y, opcionalmente, filtra otros datos. En el ejemplo, la comprensión incluye los códigos cuya RAM es al menos 8. Mantén estas expresiones breves para que sea fácil identificar qué seleccionan y qué producen. sorted devuelve una lista nueva ordenada. Su argumento key permite indicar el valor que debe utilizarse al comparar los elementos.

Sigue el ejemplo: equipos asocia cada código con una cantidad de RAM. La comprensión guarda PC01 y PC02 en aptos porque cumplen ram >= 8. Después, sorted ordena los códigos para mostrarlos. El diccionario original conserva sus datos.

2.2 Compartir no es copiar

Cuando escribes b = a y a contiene una lista, ambos nombres quedan asociados al mismo objeto. La asignación conserva una referencia a esa lista. Si ejecutas b.append(2), modificas la lista compartida y el cambio también se observa al consultar a. Este comportamiento se parece a asignar en Java una referencia a un ArrayList a otra variable.

En cambio, b = a.copy() crea una lista exterior diferente con los mismos elementos. Si añades o eliminas elementos de b, la estructura exterior de a conserva los suyos. Esta copia se llama superficial porque reutiliza las referencias a los elementos. Si un elemento es otra lista, esa lista interior queda compartida y sus modificaciones se observan desde ambas listas exteriores.

Esta distinción importa al diseñar clases. Si un método devuelve directamente la lista interna de un objeto, quien lo llama puede añadir o borrar elementos sin pasar por las operaciones previstas. Devolver una tupla permite consultar una colección cuya estructura no se puede cambiar. Aun así, los objetos que contiene pueden seguir siendo modificables. Decide qué operaciones debe permitir cada resultado.

Utiliza == para comparar valores e is para comprobar si dos nombres se refieren al mismo objeto. Dos listas pueden tener el mismo contenido y ser objetos distintos. La comprobación x is None es una forma habitual de identificar la ausencia de un valor. Para comparar números o textos, utiliza ==.

Sigue el ejemplo: copia es una lista exterior distinta de original, por eso original is copia muestra False. Sin embargo, original[0] y copia[0] apuntan a la misma lista interior y su comparación con is muestra True. Al añadir PC02 a esa lista, print(original) muestra [['PC01', 'PC02']].

2.3 Operar con secuencias y recorrer sin sorpresas

Las listas y las cadenas son secuencias cuyos índices comienzan en cero. datos[0] obtiene el primer elemento y datos[-1] el último. Si la secuencia está vacía, esos accesos provocan IndexError. Un corte como datos[1:3] selecciona los elementos de las posiciones 1 y 2. La posición final queda excluida. En una lista, el corte crea otra lista exterior y conserva las referencias a los elementos seleccionados. En una cadena, obtienes la subcadena correspondiente. Esos elementos interiores, cuando existen, se siguen compartiendo.

El método append añade un único elemento al final de una lista. extend recorre un iterable y añade sus elementos por separado. Por ejemplo, partiendo de [1, 2], append([3, 4]) produce [1, 2, [3, 4]], mientras que extend([3, 4]) produce [1, 2, 3, 4]. Comprueba qué estructura necesita el programa antes de elegir una operación.

Métodos como append y sort modifican la propia lista y devuelven None, que representa la ausencia de un resultado útil en esa llamada. Si escribes datos = datos.sort(), el nombre datos terminará asociado a None. Puedes escribir datos.sort() para ordenar esa lista o nueva = sorted(datos) para obtener otra ordenada y conservar la original.

Si borras elementos de una lista mientras la recorres, las posiciones restantes se desplazan y el bucle puede saltarse datos. Para filtrar, construye otra lista con los elementos que deben conservarse. Antes de emplear una comprensión, escribe su bucle equivalente y comprueba qué se añade en cada vuelta.

Sigue el ejemplo: El recorrido añade 16 y 8 a aptas en ese orden. sorted(ram) produce [4, 4, 8, 16]. Por último, print(ram) confirma que la lista original sigue siendo [4, 16, 8, 4].

Desde Java: ArrayList<Equipo> permite expresar en Java qué tipo de elementos admite la colección. Una lista de Python puede contener objetos de tipos diferentes. En este proyecto mantendremos un contenido coherente con la finalidad de cada colección para que sus operaciones sean previsibles.

OjoTras lista = lista.append(x), append ya ha añadido x al objeto, pero la asignación asocia el nombre lista con None. Para conservar el acceso a la lista, escribe lista.append(x) sin asignar su resultado.

2.4 Diccionarios: altas, consultas y duplicados

Un diccionario asocia claves únicas con valores. La asignación inventario[codigo] = ficha crea una entrada si la clave está ausente y sustituye su valor si ya existe. Cuando la aplicación debe rechazar códigos duplicados, es necesario comprobar codigo in inventario antes de asignar. El diccionario garantiza la unicidad de las claves, pero admite actualizar su valor.

Al recorrer un diccionario directamente, for obtiene sus claves. Utiliza items() para recibir cada pareja de clave y valor. get permite consultar una clave y ofrecer un resultado alternativo si falta. Si None también es un valor válido, get(clave) por sí solo no permite distinguir entre una clave ausente y una presente con valor None. Comprueba la pertenencia con in cuando necesites distinguir ambas situaciones.

Decide cómo representarás los códigos y aplica la misma regla al dar de alta y al buscar. Si " pc01 " y "PC01" identifican el mismo equipo, codigo.strip().upper() elimina los espacios exteriores y convierte las letras a mayúsculas. Esta preparación se llama normalización. Si solo normalizas al insertar, una búsqueda con espacios o minúsculas podría fallar.

Guarda cada dato en un lugar que permita mantenerlo coherente. Por ejemplo, si el código ya es la clave del diccionario, una segunda copia editable dentro de la ficha podría acabar siendo diferente. Si necesitas almacenar ambas representaciones, tendrás que mantenerlas sincronizadas.

Sigue el ejemplo: strip().upper() convierte " pc01 " en "PC01". Como el inventario está vacío, se añade la ficha. El recorrido muestra PC01 8 y la comprobación de pertenencia muestra True.

2.5 Tuplas, conjuntos y elección razonada

Elige la colección según las operaciones que necesite el problema. Una lista permite mantener y editar una secuencia ordenada de tareas. Una tupla sirve para devolver una agrupación fija, como una pareja de resultados. Un conjunto reúne las etiquetas sin repetirlas. Un diccionario permite localizar una ficha mediante una clave, como el código de un equipo.

Los conjuntos permiten calcular unión, intersección y diferencia. La unión reúne los elementos de ambos conjuntos. La intersección conserva los comunes. La diferencia A - B conserva los que están en A y faltan en B. Al comparar inventarios, estas operaciones permiten detectar altas, bajas y coincidencias. Utiliza sorted al presentar el resultado si necesitas un orden estable. Para crear un conjunto vacío escribe set(), ya que {} crea un diccionario.

8.1 Protocolos y métodos especiales

Un protocolo es un conjunto de operaciones que permite utilizar un objeto de una determinada manera. Python utiliza métodos especiales para conectar nuestras clases con sus operaciones habituales. Al definir __len__, permites consultar len(objeto), que debe dar un entero no negativo. Al definir __iter__, permites obtener un iterador para recorrer el objeto con for.

__str__ devuelve una representación legible, que utiliza print al mostrar el objeto. __repr__ devuelve una representación útil al inspeccionarlo durante la depuración. Ambos deben devolver str. Guarda los datos mediante un formato diseñado para recuperarlos, como el JSON que estudiaremos después. El texto de presentación puede cambiar sin conservar la información necesaria para reconstruir el objeto.

Decide también qué significa que dos objetos sean iguales. Dos resúmenes pueden compararse por sus campos, mientras que dos equipos con la misma descripción pueden representar unidades diferentes. Si defines __eq__ y recibes un tipo con el que desconoces cómo comparar, devuelve NotImplemented para que Python continúe su mecanismo de comparación.

Recuerda la diferencia con la identidad. is comprueba si se trata del mismo objeto. == solicita la comparación de valores definida por el tipo. En Java, comparar referencias con == se corresponde más con la idea de identidad, mientras que equals permite definir una comparación lógica.

8.5 Igualdad, identidad y decisiones de dominio

is comprueba si dos referencias identifican el mismo objeto. == utiliza la comparación que ofrece su tipo. Aunque decidas que dos equipos con el mismo código se comparen como iguales, Inventario seguirá necesitando rechazar el registro duplicado. La igualdad no sustituye a esa regla.
